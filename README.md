# Mon Budget — V1.0.4

Application PWA de gestion de deux budgets permanents.

## Nouveautés

- suppression de la navigation mensuelle ;
- espace **Personnel** permanent ;
- espace **Compte commun** totalement indépendant ;
- barre de navigation inférieure ;
- réglages pour renommer les espaces ;
- export et import d'une sauvegarde JSON ;
- migration automatique des données personnelles de la V1.0.3 ;
- sauvegarde locale et fonctionnement hors connexion.
