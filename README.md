# Mon Budget — Version 1.0.0

## Publication sur GitHub Pages

1. Créez un nouveau dépôt GitHub.
2. Ajoutez tous les fichiers et le dossier `assets` à la racine du dépôt.
3. Ouvrez **Settings → Pages**.
4. Dans **Build and deployment**, choisissez **Deploy from a branch**.
5. Sélectionnez la branche `main` et le dossier `/ (root)`.
6. Ouvrez l’adresse fournie par GitHub après le déploiement.

## Installation sur iPhone

1. Ouvrez l’adresse de l’application dans Safari.
2. Touchez le bouton **Partager**.
3. Choisissez **Sur l’écran d’accueil**.
4. Confirmez avec **Ajouter**.

## Données

Les données sont enregistrées uniquement dans le navigateur de l’appareil avec `localStorage`. Effacer les données Safari ou supprimer les données du site supprimera le budget enregistré.
